# Checklist Lancement — GlamBrush Shopify

À compléter avant de publier la boutique. Objectif : zéro friction pour la première cliente.

---

## PRODUIT & CONTENU

- [ ] **1. Fiche produit complète**
  - Titre optimisé avec mots-clés (nettoyeur pinceaux électrique USB)
  - Description longue > 300 mots avec bénéfices + mots-clés
  - Prix : 24,99 € | Prix barré : 74,99 € | Badge -67%
  - Minimum 4 photos haute résolution (1200x1500px minimum)

- [ ] **2. Images produit**
  - Photo principale : fond blanc, produit centré
  - Photo lifestyle : en situation d'utilisation
  - Photo accessoires : les 8 adaptateurs
  - Photo résultat : pinceaux avant/après
  - Toutes en WebP ou JPEG qualité 85%+

- [ ] **3. Vidéo produit** (fort impact conversion)
  - Démonstration 15-30 secondes
  - Uploadée en MP4 < 10MB (optimisée)
  - Alternative image si pas de vidéo

- [ ] **4. Textes sections**
  - Hero : headline + sous-titre + badge urgence saisis
  - Bénéfices : 4 cards remplies avec titres et descriptions
  - How it works : 3 étapes avec emojis ou images
  - FAQ : 8 questions remplies (template inclus dans la section)
  - Avis : minimum 6 avis saisis avec noms + dates + textes

---

## CONFIGURATION SHOPIFY

- [ ] **5. Domaine personnalisé** connecté et SSL actif (https://)

- [ ] **6. Passerelle de paiement** configurée
  - Stripe ou Shopify Payments activé
  - PayPal ajouté (augmente conversion ~15%)
  - Apple Pay / Google Pay activés

- [ ] **7. Modes de livraison**
  - Livraison standard : délai 3-5j, tarif ou offerte
  - Seuil livraison gratuite configuré (ex : dès 30€)
  - Politique de retour 30 jours rédigée (/policies/refund-policy)

- [ ] **8. Emails transactionnels** customisés
  - Confirmation de commande avec branding GlamBrush
  - Email de suivi livraison
  - Email de relance panier abandonné (Klaviyo ou natif Shopify)

- [ ] **9. Pages légales** créées
  - Mentions légales
  - CGV / Conditions générales de vente
  - Politique de confidentialité (RGPD)
  - Politique de retour/remboursement

---

## SEO & TRACKING

- [ ] **10. Google Analytics 4** pixel installé (via Shopify Admin → Preferences)

- [ ] **11. Meta Pixel** (Facebook/Instagram) configuré pour retargeting

- [ ] **12. Google Search Console** : site vérifié + sitemap soumis

- [ ] **13. Meta description** page d'accueil saisie dans Shopify Admin → Preferences

- [ ] **14. Structured Data vérifié**
  - Tester sur Google Rich Results Test : https://search.google.com/test/rich-results
  - Product markup valide
  - FAQ markup valide

---

## PERFORMANCE

- [ ] **15. PageSpeed Insights** score
  - Mobile > 70 (cible : > 85)
  - Desktop > 90
  - Tester sur : https://pagespeed.web.dev/

- [ ] **16. Images optimisées**
  - Toutes < 200KB (héro < 400KB)
  - Format WebP activé (Shopify le fait automatiquement)
  - Attributs `width` et `height` présents sur toutes les `<img>`

- [ ] **17. Test mobile**
  - Testé sur iPhone (Safari) et Android (Chrome)
  - Bouton ATC visible et cliquable sans zoom
  - Texte lisible sans zoom (min 16px)
  - Sticky ATC fonctionne au scroll

---

## CONVERSION

- [ ] **18. Tunnel d'achat testé**
  - Ajouter au panier → fonctionne
  - Checkout → paiement test réussi
  - Email confirmation reçu
  - Sticky ATC apparaît au scroll

- [ ] **19. Urgency Bar**
  - Compte à rebours actif
  - Message pertinent et crédible
  - Stock indicator réaliste (pas 0, pas 100%)

- [ ] **20. Trust signals visibles**
  - Livraison gratuite affichée dans announcement bar + hero + footer
  - Retour 30 jours visible
  - Avis clients > 4.5 étoiles
  - Badges sécurité paiement en footer

---

## AVANT PUBLICATION

```
□ Désactiver le mode mot de passe (Online Store → Preferences → Password)
□ Vérifier que le bon thème est "publié" (Published)
□ Test commande réelle avec carte bancaire de test Shopify
□ Vérifier les redirections 301 si migration depuis un autre site
□ Sauvegarder le thème avant toute modification (Actions → Duplicate)
```
